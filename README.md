# deepseek-kali

Запуск DeepSeek через nodriver + Chromium в Kali Linux.

## Установка

git clone https://github.com/ТВОЙ_НИК/deepseek-kali.git
cd deepseek-kali
bash setup.sh

## Запуск

ds

Или: source ~/antidetect/venv/bin/activate && python3 ~/antidetect/deepseek_launcher.py

## Требования

- Kali Linux
- Python 3.11+
- Интернет
